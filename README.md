# Mood Checker App 🎭

A simple and interactive Mood Checker web application built using HTML, CSS, and JavaScript.

Users can select their mood, and the application dynamically changes the background color and displays a motivational message.

---

## 🚀 Features

- 😊 Happy Mood
- 😔 Sad Mood
- 😡 Angry Mood
- Dynamic background color changes
- Interactive button hover effects
- Responsive design for mobile screens

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

---

## 📂 Project Structure

├── index.html
├── style.css
└── app.js

---

## 📖 How It Works

Each button triggers a JavaScript function:

- Changes the heading text
- Updates the background color dynamically
- Creates an interactive user experience
